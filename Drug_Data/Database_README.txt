PeakMeister has the ability to check the adherence of detected drugs as well as potentially detect drug-drug interactions. This requires access to two large datasets. The first database required is the complete or "all-drugs" DrugBank database. Researchers can acquire an academic license for this database for free if they meet the following criteria:

1. You’re a student, professor, or research associate with an academic institution
2. Your research is not primarily for the benefit of a commercial third party
3. You’re building a tool solely for academic purposes

This database is extremely extensive and is time-consuming to parse. Because of this, this database will NOT be included with the PeakMeister download, and users must acquire it themselves.DrugBank link: https://go.drugbank.com/releases/latest

The second database is the TWOSIDES database from nSIDES; the drug side effect and interaction database. This database is large, but free for anyone to access. Users can download the TWOSIDES database here: https://nsides.io/#offsides-and-twosides

PeakMeister will require the user to download the zip or xml versions of these databases manually.
